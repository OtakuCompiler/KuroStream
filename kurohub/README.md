# KuroStream Website

The official website for KuroStream — an open-source Android TV streaming app.

## Stack
- **Framework**: TanStack Start + React 19
- **Styling**: Tailwind CSS v4 + shadcn/ui
- **Auth**: Firebase Authentication
- **Database**: Cloudflare D1 (SQLite)
- **Cache**: Cloudflare KV
- **Animations**: Framer Motion
- **Deploy**: Cloudflare Workers

## Quick Start
```bash
npm install
npm run dev
```

## Deploy
```bash
npm run build
npm run deploy
```
